# Changelog

## 1.1.0 — 2026-10-08

First public source release.

- Menu bar checkmark opens the Microsoft To Do web interface.
- Compact popover supports task entry and completion through Microsoft's website.
- Pin option, navigation controls, right-click menu, and persistent web session.
- Portable build and packaging scripts with embedded MIT license.
- Apple silicon build with SHA-256 checksum; ad-hoc signed, not notarized.
